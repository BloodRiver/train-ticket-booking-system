# Task
Steps:
1. Open a file named `student_grades.txt`
2. Take the name, student id, chemistry marks, physics marks, and computer science marks as **input from the user**
3. Determine the grade of the 3 courses according to marks.

**Grading Scheme**

Marks | Grade
----- | -----
90 - 100 | A*
80 - 89 | A
70 - 79 | B
60 - 69 | C
50 - 59 | D
Otherwise | F (Fail)


4. Output the Student ID, Student Name, Chemistry Grade, Physics Grade, Computer Science Grade to `student_grades.txt`

**Example `students.txt`**:
```text
Student ID, Student Name, Chemistry Grade, Physics Grade, Computer Science Grade
1234, Sajeed, A*, A, A*
2345, Shahrear, A, A, A*
3456, Arnob, B, C, D
```

5. Close `students.txt` file using the `.close()` function
